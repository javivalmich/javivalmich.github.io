# Punto Studio

Web de inicio de **puntostudio.es**: portada con los dos juegos, y las páginas comunes de privacidad y soporte.
HTML y CSS a mano, sin dependencias ni scripts externos.

- `/` portada · `/privacidad/` · `/soporte/` · `404.html` (también redirige las direcciones antiguas de los juegos)
- Los juegos viven en sus repos: `punto-falso` y `punto-ciego` (cada uno con su `beta/`), servidos como `/punto-falso/` y `/punto-ciego/`.
- Contacto único: `soporte@puntostudio.es`. La política de privacidad es una sola (`/privacidad/`): las páginas `privacidad.html` de cada juego redirigen aquí. No se carga nada externo (ni tipografías).
- `fase2/`: guion y comprobador de la mudanza desde `javivalmich.github.io` (no se publica).
